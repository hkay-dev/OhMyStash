# OhMyStash: Cap nativeBrowserSpec search payloads and fall back on large edits and 3 more

Changed: The native stash browser now copes with very large stashes, uses your Editor command for Edit, and keeps its place when you cancel Send; shared shortcut hints read right on Windows and Linux, and other plugins' pickers can open as native dialogs.
Try: In Harrier, open the stash browser, scroll down, send a stash with more than one send target installed and press Esc on the picker; not tried yet.

## What changed

- Fixed: The native stash browser no longer breaks on very large stashes, and Edit uses your Editor command. (ohmystash#nn1j)
- Fixed: Cancelling the Send picker in the native browser keeps your place in the list, and deleting the last stash shows one message. (ohmystash#edjz)
- Fixed: Shortcut hints show Ctrl, Alt and Super on Windows and Linux, and read cmd and opt keys right. (ohmystash#05x6)
- New: Plugins that use the shared option picker can show it as a native dialog when the terminal app offers one. (ohmystash#n7m4)

## Calls

- The native option is a 'native: { events, id }' field on selectOption's settings, not a new argument; a cancel in the native dialog returns nothing and doesn't open the terminal picker. (ohmystash#n7m4)
- Native browser search matches a stash's metadata and the first 1,000 characters of its text, not the whole prompt; a native host that fails after an action closes the browser without an error message. (ohmystash#nn1j)
